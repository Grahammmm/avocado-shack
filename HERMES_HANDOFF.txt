PRIVATE SANDBOX
Only bind to 127.0.0.1. No public proxy, tunnel URL, DNS change or publication.
Service: avocado-shack-sandbox.service (user service).
  systemctl --user status avocado-shack-sandbox.service
  systemctl --user restart avocado-shack-sandbox.service
  journalctl --user -u avocado-shack-sandbox.service -n 50 --no-pager
Environment file: private runtime data /sandbox.env (contains DB path, no mail keys).
Database: private runtime data /community.sqlite3
The Git-ignored repo path community-data points to the private data directory.

To start manually (stop the service first to avoid a port conflict):
  AVOSHACK_COMMUNITY_DB=/home/user/.local/share/avocado-shack/community.sqlite3 \
    python3 /home/user/repos/avocado-shack/storefront-mockup/community-server.py --port 3101

From the Mac, when local port 3101 is free:
  ssh -N -L 127.0.0.1:3101:127.0.0.1:3101 agentorange
Then view http://127.0.0.1:3101/ on the Mac. This uses private SSH access.
Do not change the local port without adjusting server Host/Origin validation.
